# Lanework

A kanban board for the Mac whose boards are plain folders of Markdown, so you and your agents work the same board.

[laneworkapp.com](https://laneworkapp.com)

## Repositories

| repo | what it is |
|---|---|
| [lanework-marketplace](https://github.com/laneworkapp/lanework-marketplace) | Claude Code plugins for Lanework boards. Start here to install them. |
| [lanework-skills](https://github.com/laneworkapp/lanework-skills) | The agent skills behind the `lanework` plugin. |
| [lanework-templates](https://github.com/laneworkapp/lanework-templates) | Board templates for the app's New Board gallery. |
| [lanework-support](https://github.com/laneworkapp/lanework-support) | Report a problem or ask for a feature. |
